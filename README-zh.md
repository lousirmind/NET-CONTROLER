# VibeNet Control（可控力场）

一款基于 macOS 的网络管理工具，通过 ARP 欺骗（ARP Spoofing）技术实现对局域网设备的流量拦截与网络控制。提供终端命令行（CLI）和浏览器 Web 界面两种操作方式。**仅供教育和网络测试使用。**

## 功能特性

- **网络扫描** — 发现局域网内所有活跃设备，显示 IP、MAC 地址及厂商名称（使用 nmap OUI 数据库 + 中国品牌补充库 + 在线 API 回退）。
- **真实设备 vs. 随机化 MAC 检测** — 自动区分真实连接设备与使用随机化 MAC 的路过扫描设备（iOS/Android 隐私特性）。
- **ARP 欺骗** — 拦截目标设备与网关之间的通信流量（中间人攻击）。
- **断网开关（Kill Switch）** — 一键切断目标设备的互联网访问。
- **多目标控制（GUI）** — 在 Web 界面中同时管理多个目标设备。
- **紧急停止** — 一键恢复所有活跃的欺骗会话和系统转发设置。
- **安全恢复** — Ctrl+C（CLI）或紧急停止按钮（GUI）始终触发完整的 ARP 恢复流程。

## 使用说明

### Web 界面（推荐）

```bash
bash run.sh --gui
```

浏览器自动打开 `http://localhost:8501`。

1. 点击左侧边栏的 **Scan Network** 按钮。
2. 设备分为两个独立表格展示：
   - **真实设备**（Connected Devices）— 绿色行，完整厂商信息，可操作。
   - **路过扫描设备**（Nearby Scanning）— 蓝色行，灰色字体，只读。
3. 下方设备控制区，每台真实设备有 **Kill** 按钮。
4. 已断网的设备显示 **Restore** 按钮以恢复上网。
5. 页面底部 **Emergency Stop** 按钮可一键恢复所有设备。

### 命令行界面（CLI）

```bash
sudo python3 main.py
```

| 命令 | 操作 |
|------|------|
| `k` | **断网** — 切断目标互联网（关闭 IP 转发） |
| `u` | **恢复** — 恢复目标互联网（开启 IP 转发） |
| `q` | **退出** — 停止欺骗，恢复 ARP 并退出 |
| `Ctrl+C` | **紧急停止** — 立即恢复一切并退出 |

### 独立扫描器

```bash
sudo python3 core/scanner.py
```

## 工作原理

```
                    ┌──────────────┐
    目标设备 ──ARP──> │   本机 Mac   │ ──ARP──>  网关
                    │   (转发器)   │
                    └──────────────┘
```

1. **ARP 投毒**：工具持续发送伪造的 ARP 应答，告诉目标设备"我就是网关"，同时告诉网关"我就是目标设备"。双方更新的 ARP 缓存将流量发送到错误的 MAC 地址——也就是我们的机器。

2. **IP 转发**：`net.inet.ip.forwarding=1` 时，Mac 将拦截到的数据包在网卡之间路由，目标设备正常上网（但所有流量经过我们）。

3. **断网开关**：`net.inet.ip.forwarding=0` 时，Mac **静默丢弃**所有转发的数据包。目标设备的流量到达本机后被丢弃，无法到达互联网。

4. **恢复**：退出时向目标设备和网关各发送 3 轮正确的 ARP 应答（含真实 MAC 映射），确保双方 ARP 缓存立即恢复正常。

## 厂商数据库

工具使用三层机制识别 MAC 厂商：

| 层级 | 来源 | 条目数 | 速度 |
|------|------|--------|------|
| 1. 本地主库 | nmap `nmap-mac-prefixes` | 52,091 | 即时 |
| 2. 本地补充库 | `oui_supplement.txt` | ~2,900 | 即时 |
| 3. 在线回退 | maclookup.app API | — | ~1-3秒（自动缓存） |

补充数据库广泛覆盖中国手机品牌（小米、华为、OPPO、vivo、一加、真我、魅族、中兴、努比亚、联想、TCL、海信等），以及 IoT 设备、无人机（大疆）、网络设备。

随机化 MAC 地址（iOS/Android 在 Wi-Fi 扫描时使用）会被自动识别并标记——这类地址本质上无法解析为厂商。

## 安全注意事项

- 本工具发送原始 ARP 数据包，会修改网络中其他设备的 ARP 缓存。**仅在你拥有或明确获得测试许可的网络上使用。**
- `main.py` 中的 `finally` 代码块和 GUI 的紧急停止按钮保证在任何退出路径上都会发送恢复数据包。
- 退出时 **始终关闭** IP 转发，恢复系统正常行为。
- 随机化 MAC 设备无法作为目标——它们的地址是临时的，随时会变化。
